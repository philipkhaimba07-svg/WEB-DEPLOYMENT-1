# SpendWise

## Project Description
SpendWise is a web-based expense tracker for people who want to know where their money goes. Users set a monthly budget in KES, add expenses with a category, filter them, delete entries, and see a progress bar and spending-by-category chart update as they go.

## Technologies Used
HTML, CSS, JavaScript, Git, GitHub, Netlify, Visual Studio Code.

## GitHub Repository Information
Repository: https://github.com/philipkhaimba07-svg/week-6-web-development-
Branch deployed: main

## Live Website
https://spendwise-phil.netlify.app

## Deployment Process Summary
I pushed the SpendWise project to a public GitHub repository, then signed in to Netlify and imported the repository as a new site. Netlify published it at the URL above. I tested adding, deleting, and filtering expenses, setting a budget, and the category breakdown on the live site. I then made a small update locally, pushed it to GitHub, and confirmed in the Netlify Deploys tab that the site rebuilt and published automatically.
